 # Recursos utilizados
 En esta parte del proyecto hemos utilizado 3 repositorios GitHubs donde en el master se deja como en el dia 1 ya que se usará
 para aplicar el proyecto final,mientras que en la rama develope será cuando queramos hacer pruebas de que todo funciona antes
 de enviarlo al master y el Sprint1 es donde se guardará todo el progreso realizado en este lapso de tiempo,cada vez que empezemos
 un Sprint,con Vs Code hemos usado para programar toda la pagina
 
 **Docker:** herramienta que permite crear y ejecutar contenedores para servicios como la base de datos o el backend de forma aislada.
 
 **Git:** sistema de control de versiones que usamos para gestionar cambios, mantener historial y colaborar de forma ordenada.

**GitHub:** plataforma donde alojamos el repositorio del proyecto, gestionamos issues, tareas y revisiones de código.
