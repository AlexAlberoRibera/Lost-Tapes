| Pérdida de datos de usuarios o productos                   | Media        | Alta    | Realizar copias de seguridad regulares, validar todos los datos en frontend y backend, utilizar bases de datos con integridad y transacciones.                             | Equipo backend                 | Revisión semanal de copias y comprobación del funcionamiento de la base de datos. |
| Fallas de seguridad o ataques externos                     | Media        | Alta    | Validar y limpiar todas las entradas de usuario, usar HTTPS, almacenar contraseñas de manera segura, actualizar dependencias y monitorizar intentos de acceso sospechosos. | Equipo backend y frontend      | Monitorización continua y revisión de logs semanal.                               |

| Problemas de compatibilidad con navegadores                | Baja         | Media   | Probar la web en los principales navegadores (Chrome, Firefox, Edge, Safari), usar HTML5 y CSS3 estándar y revisar la funcionalidad en dispositivos móviles.               | Equipo frontend                | Pruebas de compatibilidad antes de cada entrega.                                  |
| Caída del servidor o tiempo de inactividad                 | Baja         | Alta    | Elegir hosting fiable, configurar monitorización y alertas, preparar planes de recuperación y redundancia si es necesario.                                                 | Equipo backend                 | Comprobación periódica del servidor y pruebas de recuperación.                    |
| Errores en el frontend (formularios, interacción, diseño)  | Media        | Media   | Validar formularios con JavaScript y PHP, realizar pruebas funcionales, revisar diseño responsive y asegurar una experiencia de usuario coherente.                         | Equipo frontend                | Pruebas semanales y corrección inmediata de errores detectados.                   |
| Problemas legales o derechos de autor                      | Baja         | Alta    | Usar solo contenido propio o con licencias libres, revisar imágenes, íconos y textos, documentar fuentes y permisos.                                                       | Equipo de gestión del proyecto | Revisiones puntuales antes de publicar cualquier contenido.                       |
| Riesgos durante el despliegue o actualizaciones            | Media        | Media   | Separar entorno de desarrollo y producción, usar control de versiones (Git), realizar pruebas completas antes de subir a producción.                                       | Equipo de desarrollo           | Control de versiones y registro de despliegues con notas de incidencias.          |
